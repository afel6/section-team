This repo is a small command-line tool that keeps track of the things you lend to people (see README.md), and its tests pass. Work on it as you would on a teammate's project.

Problems users ran into
1. "I typed `--due 2026-02-30` by mistake when I lent out my drill. It was accepted, and `list` now shows the drill as due 2026-03-02."
2. "I had lent out three things, #1 to #3. I removed #2 because I had typed it wrong and added it again, and the new loan got #3, the same number as my ladder. Then `back 3` marked the ladder as returned instead of the new loan."

README.md describes how the tool is meant to work: where the code disagrees with it, the code is wrong. Fix both problems without adding features. Leave the loans already saved in people's data files as they are: those files must keep working as they are, with no migration step.

Keep the existing tests passing and add tests for your fixes.
