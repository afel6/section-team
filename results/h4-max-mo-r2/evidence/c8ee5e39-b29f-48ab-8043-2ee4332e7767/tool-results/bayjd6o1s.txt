Build a meeting-room booking app: an HTTP server `server.mjs` (an ES module, run as `node server.mjs`) that serves a JSON API and a browser page, and keeps its data in one JSON file.

Server
- At startup the server checks `PORT`, then reads the data file, then starts listening, in that order.
- It listens on 127.0.0.1 at the port in the `PORT` environment variable. An unset or empty `PORT` means 3000. A `PORT` that is not made only of ASCII digits 0-9, or whose value is above 65535, or a port that cannot be bound (for example because it is in use), makes the server write one line of its choice to stderr and exit with code 1.
- Once listening, it prints `listening on http://127.0.0.1:<port>` followed by "\n" to stdout, where `<port>` is the port actually bound (with `PORT=0`, the port the OS picked). This line is the only thing the server ever writes to stdout.
- Its data lives in the file named by the `DATA_FILE` environment variable, as JSON in a layout of your choice. An unset or empty `DATA_FILE` means `bookings.json`. A relative `DATA_FILE`, the default included, is resolved against the current working directory, not the folder of `server.mjs`.
- The server reads the data file once, at startup. If reading it fails with `ENOENT` (the file, or a folder on its path, does not exist), there are no bookings yet. If reading it fails in any other way (for example the path is a directory), or its content is not data in the layout this server writes (for example it is empty or not valid JSON), the server writes `cannot read data file <name>` followed by "\n" to stderr, where `<name>` is the value of `DATA_FILE` as given (`bookings.json` when it is unset or empty), and exits with code 1 without listening.
- After startup the server's memory is the truth: changes made to the file from outside are not noticed. The server writes the data file only when a POST creates a booking or a DELETE removes one, never at startup or for any other request, and it never creates folders.
- Every change is saved to the data file before its reply is sent: after a restart with the same `DATA_FILE`, the bookings, and the id the next booking will get, are as before.
- If saving a change fails (for example because the data file's folder does not exist), the reply is 500 `internal error` and nothing changes, the next id included. Any other unexpected failure while handling a request also replies 500 `internal error`. In both cases the server keeps running.
- Requests that arrive at the same time give the same result as if they had been handled one at a time in some order: of several overlapping bookings sent at once while saving works, exactly one is created and every other one gets 409, and no id is given twice.
- Before sending any reply, the server reads the whole request body, if there is one, and discards what it does not use, so the client always receives the reply, the 413 and 415 replies included.

API
- The rooms are fixed: `Aurora`, `Borealis` and `Cosmos`, in that order.
- A booking is a JSON object with exactly the keys `id`, `room`, `title`, `date`, `start` and `end`: `id` is a number, the others are strings. The first booking gets id 1 and each new booking the next integer; an id is never reused, even after deletes and restarts.
- Only the parsed JSON of a reply body matters: whitespace and key order in it are free.
- A request's path is its request target up to the first `?` (all of it when there is no `?`). Routes compare the path byte for byte, with no percent-decoding and no dot-segment, slash or letter-case normalisation: `/api/%62ookings`, `/api/./rooms`, `/API/rooms` and `/api/bookings/` are none of the paths below. The query, the text after the first `?`, is ignored unless stated, and is decoded as `new URLSearchParams(query)` does.
- `GET /api/rooms`: 200 `{"rooms": ["Aurora", "Borealis", "Cosmos"]}`.
- `GET /api/bookings`: 200 `{"bookings": [...]}` with every booking, sorted by date, then start, then room in the order above. When the query has a `date` parameter (as `params.has('date')` says; `?date` with no `=` counts, with the empty value), its value is `params.get('date')` (the first one when repeated) and the reply holds only the bookings on that date; a value that is not a valid date by rule 6 below (the empty value included) gets 400 `date must be a valid YYYY-MM-DD date`. Other query parameters are ignored.
- `POST /api/bookings` with a JSON body holding `room`, `title`, `date`, `start` and `end`: 201 and the new booking. Other keys in the body are ignored.
- `DELETE /api/bookings/<id>`: every path that is `/api/bookings/` followed by a non-empty `<id>` holding no `/` is this route, whatever `<id>` is. The reply is 204 with an empty body, and the booking is gone. When `<id>` is not a positive integer written in ASCII digits 0-9 without a leading zero, or no booking has that id: 404 `booking not found`.
- `GET /` and `GET /app.js` serve the page (see Page).
- Any other path: 404 `not found`, whatever the method. This includes every path that starts with `/api/bookings/` and whose rest is empty or holds a `/`, such as `/api/bookings/` and `/api/bookings/1/`.
- A path above with a method not listed for it (HEAD and OPTIONS included): 405 `method not allowed`. For example `GET /api/bookings/abc` is 405. A 405 reply may or may not have an `Allow` header; it is not checked.
- Every reply with a body other than the page and the script has `Content-Type: application/json; charset=utf-8`. An error reply is `{"error": "<message>"}` with exactly that key, where `<message>` is the text given here.

Booking rules (`POST /api/bookings`; the first rule that fails decides the reply)
1. The media type of the `Content-Type` header (the part before the first `;`, with spaces and tabs removed from both ends, letter case ignored) is not `application/json`, or the header is missing: 415 `content type must be application/json`.
2. The body is longer than 10000 bytes, counting the body bytes actually received: 413 `body too large`.
3. The body, decoded as `Buffer.prototype.toString('utf8')` does and then given to `JSON.parse`, is not a JSON object (it is empty, not valid JSON, `null`, an array, a string, a number or a boolean): 400 `body must be a JSON object`. Bytes that are not valid UTF-8 become U+FFFD and are not an error by themselves. A byte order mark at the very start is kept, so such a body is not valid JSON.
4. `room` is not a string equal to one of the room names (letter case matters): 400 `room must be one of Aurora, Borealis, Cosmos`.
5. `title` is not a string, or is shorter than 1 or longer than 80 UTF-16 code units after removing the whitespace at both ends (as `String.prototype.trim` does): 400 `title must be 1 to 80 characters`. The booking keeps the trimmed title.
6. `date` is not a string `YYYY-MM-DD` (4, 2 and 2 ASCII digits 0-9) naming a real day from 2000-01-01 to 2099-12-31, where February has 29 days in years divisible by 4: 400 `date must be a valid YYYY-MM-DD date`.
7. `start` is not a string `HH:MM` (2 and 2 ASCII digits 0-9) from `00:00` to `23:59`: 400 `start must be HH:MM`.
8. `end` is not such a string: 400 `end must be HH:MM`.
9. `end` is not later than `start`: 400 `end must be after start`.
10. The booking overlaps a booking of the same room on the same date, that is each of the two starts before the other ends (a booking may start exactly when another ends): 409 `room is already booked from <start> to <end>`, with the start and end of the overlapping booking that starts earliest.
- No field except `title` is trimmed or changed: ` 2026-11-03`, `2026-11-3` and `9:00` are invalid.

    94	/**
    95	 * Sends one HTTP request (no agent, no keep-alive). `path` is sent as-is (no normalisation).
    96	 * `body` may be a string, a Buffer, an array of chunks (sent chunked, no Content-Length) or undefined.
    97	 * Resolves { status, headers, body: Buffer, text, json() }.
    98	 */
    99	export function request(port, { method = 'GET', path = '/', headers = {}, body } = {}) {
   100	  return new Promise((resolve, reject) => {
   101	    // Node's client does not frame bodies of GET/DELETE/OPTIONS by itself; always send a Content-Length.
   102	    const framed = body === undefined || Array.isArray(body) || hasHeader(headers, 'content-length')
   103	      ? headers
   104	      : { ...headers, 'Content-Length': String(Buffer.byteLength(body)) };
   105	    const req = httpRequest({ host: '127.0.0.1', port, method, path, headers: framed, agent: false }, (res) => {
   106	      const chunks = [];
   107	      res.on('data', (chunk) => chunks.push(chunk));
   108	      res.on('error', reject);
   109	      res.on('end', () => {
   110	        const buffer = Buffer.concat(chunks);
   111	        const text = buffer.toString('utf8');
   112	        resolve({ status: res.statusCode, headers: res.headers, body: buffer, text, json: () => JSON.parse(text) });
   113	      });
   114	    });
   115	    req.on('error', reject);
   116	    if (Array.isArray(body)) {
   117	      body.forEach((chunk) => req.write(chunk));
   118	      req.end();
   119	    } else {
   120	      req.end(body);
   121	    }
   122	  });
   123	}

   230	  }
   231	}

   236	function guard(page, kind, target, allowed) {
   237	  return new Proxy(target, {
   238	    get(obj, key) {
   239	      if (key === RAW) return obj;
   240	      // `then` is probed by the engine when a reply resolves a promise; not a script access.
   241	      const engineProbe = kind === 'reply' && key === 'then';
   242	      if (typeof key === 'string' && !allowed.has(key) && !engineProbe) page.forbidden.push(`${kind}.${key}`);
   243	      const value = Reflect.get(obj, key, obj);
   244	      return typeof value === 'function' ? value.bind(obj) : value;
   245	    },
   246	    set(obj, key, value) {
   247	      if (typeof key === 'string' && !allowed.has(key)) page.forbidden.push(`${kind}.${key}=`);
   248	      return Reflect.set(obj, key, value, obj);
   249	    },
   250	  });
   251	}

   259	/** One fetch call the test can settle: respond(), respondSlowJson(), respondUnparseable(), fail(). */
   260	class FetchCall {
   261	  constructor(page, url, options) {
   262	    this.page = page;
   263	    this.url = url;
   264	    this.options = options;
   265	    this.jsonCalls = 0;
   266	    this.bookDisabledAtCall = page.bookDisabled();
   267	    this.promise = new Promise((resolve, reject) => { this.resolve = resolve; this.reject = reject; });
   268	  }
   269	  reply(status, json) {
   270	    const call = this;
   271	    const target = { status, json() { call.jsonCalls += 1; return json(); } };
   272	    this.resolve(guard(this.page, 'reply', target, REPLY_MEMBERS));
   273	  }
   274	  /** Settles with `status` and a body that json() parses (a fresh copy each time). */
   275	  respond(status, body) {
   276	    const text = JSON.stringify(body);
   277	    this.reply(status, () => Promise.resolve(JSON.parse(text)));
   278	  }
   279	  /** Settles the status now; json() stays pending until the returned resolveJson(body) is called. */
   280	  respondSlowJson(status) {
   281	    let resolveJson;
   282	    const pending = new Promise((resolve) => { resolveJson = resolve; });
   283	    this.reply(status, () => pending);
   284	    return (body) => resolveJson(JSON.parse(JSON.stringify(body)));
   285	  }
   286	  /** Settles with `status` and a body whose json() rejects (unparseable). */
   287	  respondUnparseable(status) {
   288	    this.reply(status, () => Promise.reject(new SyntaxError('Unexpected token')));
   289	  }
   290	  /** No reply at all: fetch rejects. */
   291	  fail() { this.reject(new TypeError('Failed to fetch')); }
   292	}

   294	/** Runs app.js against a fresh fake page. Returns the page handle used by tests. */
   295	export function loadApp({ source = readFileSync(APP_PATH, 'utf8') } = {}) {
   296	  const page = { forbidden: [], log: [], calls: [], elements: {} };
   297	  page.bookDisabled = () => page.elements.book?.attrs.disabled ?? false;
   298	  Object.entries(PAGE_ELEMENTS).forEach(([id, [tag, type]]) => {
   299	    const element = makeElement(page, tag, id);
   300	    element.attrs = { ...element.attrs, type };
   301	    page.elements[id] = element;
   302	  });
   303	  page.created = [];
   304	  const document = guard(page, 'document', {
   305	    getElementById: (id) => page.elements[id]?.proxy ?? null,
   306	    createElement: (tag) => {
   307	      const element = makeElement(page, String(tag).toLowerCase(), undefined);
   308	      page.created.push(element);
   309	      return element.proxy;
   310	    },
   311	  }, DOCUMENT_MEMBERS);
   312	  const fetch = (url, options) => {
   313	    const call = new FetchCall(page, url, options);
   314	    page.calls.push(call);
   315	    return call.promise;
   316	  };
   317	  const sandbox = { document, fetch };
   318	  BROWSER_GLOBALS.forEach((name) => {
   319	    Object.defineProperty(sandbox, name, { get() { page.forbidden.push(`global.${name}`); return undefined; } });
   320	  });
   321	  vm.createContext(sandbox);
   322	  vm.runInContext(source, sandbox, { filename: 'app.js' });
   323	  return page;
   324	}

   358	// Tiny HTML parser for tests: tags, attributes and text only.
   359	const VOID = new Set('area base br col embed hr img input link meta source track wbr'.split(' '));
   360	const RAW = new Set(['script', 'style', 'title', 'textarea']);
   361	const ATTR_RE = /([^\s"'<>\/=]+)(?:\s*=\s*(?:"([^"]*)"|'([^']*)'|([^\s"'>]+)))?/y;
   362	
   363	function parseAttrs(src) {
   364	  const attrs = {};
   365	  let pos = 0;
   366	  while (pos < src.length) {
   367	    if (/[\s\/]/.test(src[pos])) { pos++; continue; }
   368	    ATTR_RE.lastIndex = pos;
   369	    const m = ATTR_RE.exec(src);
   370	    if (!m) { pos++; continue; }
   371	    attrs[m[1].toLowerCase()] = m[2] ?? m[3] ?? m[4] ?? '';
   372	    pos = ATTR_RE.lastIndex;
   373	  }
   374	  return attrs;
   375	}

   377	function closeTag(text, i, root, cur) {
   378	  const end = text.indexOf('>', i);
   379	  const name = text.slice(i + 2, end < 0 ? text.length : end).trim().toLowerCase();
   380	  let next = cur;
   381	  for (let n = cur; n && n !== root; n = n.parent) {
   382	    if (n.tag === name) { next = n.parent; break; }
   383	  }
   384	  return { cur: next, i: end < 0 ? text.length : end + 1 };
   385	}
   386	
   387	function openTag(text, i, cur) {
   388	  const m = /^<([a-zA-Z][^\s\/>]*)((?:"[^"]*"|'[^']*'|[^'">])*)>/.exec(text.slice(i));
   389	  if (!m) return null;
   390	  const tag = m[1].toLowerCase();
   391	  const node = { tag, attrs: parseAttrs(m[2]), children: [], parent: cur };
   392	  cur.children.push(node);
   393	  i += m[0].length;
   394	  if (VOID.has(tag)) return { cur, i };
   395	  if (!RAW.has(tag)) return { cur: node, i };
   396	  const close = new RegExp('</' + tag + '\\s*>', 'i').exec(text.slice(i));
   397	  const stop = close ? i + close.index : text.length;
   398	  if (stop > i) node.children.push({ text: text.slice(i, stop), parent: node });
   399	  return { cur, i: close ? stop + close[0].length : text.length };
   400	}

   402	export function parseHtml(text) {
   403	  const root = { tag: '#root', attrs: {}, children: [], parent: null };
   404	  let cur = root;
   405	  let i = 0;
   406	  const addText = (t) => { if (t) cur.children.push({ text: t, parent: cur }); };
   407	  while (i < text.length) {
   408	    const lt = text.indexOf('<', i);
   409	    if (lt < 0) { addText(text.slice(i)); break; }
   410	    addText(text.slice(i, lt));
   411	    i = lt;
   412	    if (text.startsWith('<!--', i)) {
   413	      const end = text.indexOf('-->', i + 4);
   414	      i = end < 0 ? text.length : end + 3;
   415	    } else if (text.startsWith('<!', i) || text.startsWith('<?', i)) {
   416	      const end = text.indexOf('>', i);
   417	      i = end < 0 ? text.length : end + 1;
   418	    } else if (text.startsWith('</', i)) {
   419	      ({ cur, i } = closeTag(text, i, root, cur));
   420	    } else {
   421	      const r = openTag(text, i, cur);
   422	      if (!r) { addText('<'); i++; } else { cur = r.cur; i = r.i; }
   423	    }
   424	  }
   425	  return root;
   426	}

   428	export function findAll(root, predicate) {
   429	  const out = [];
   430	  const walk = (n) => {
   431	    for (const c of n.children ?? []) {
   432	      if (c.tag === undefined) continue;
   433	      if (predicate(c)) out.push(c);
   434	      walk(c);
   435	    }
   436	  };
   437	  walk(root);
   438	  return out;
   439	}
